# Mandatory Project Rule: Zero Dummy, Demo, or Temporary Data

1. **NO MOCK OR DUMMY DATA:** Never add fake rows, placeholder metrics, hardcoded demo counts, or simulated dummy arrays anywhere in the frontend, backend, or database.
2. **NO TEMPORARY CODE:** Do not add temporary hacks, stubbed endpoints, or throwaway components. Every piece of code written must be production-grade.
3. **AUTHENTIC CALCULATIONS ONLY:** All computed outputs must derive strictly from real user inputs and verified formulas.
4. **REAL DATABASE PERSISTENCE:** The database must always start at 0 records and update dynamically only through real user submissions and verified actions.
