# General Brainstorming & Collaborative Ideation Skill

This skill guides structured design thinking, requirement discovery, and architectural decision logging for any software project.

---

## 1. The 4-Step Brainstorming Framework

```
[ 1. Diverge ] ──▶ [ 2. Group & Categorize ] ──▶ [ 3. Prioritize (2x2 Matrix) ] ──▶ [ 4. Converge & Record ]
```

### Phase 1: Divergent Thinking
- Explore ideas freely without premature constraints.
- Use **SCAMPER** (Substitute, Combine, Adapt, Modify, Put to other use, Eliminate, Reverse).

### Phase 2: Theme Grouping
Group ideas into logical areas (e.g., Core Utility, User Engagement, Administration, Analytics).

### Phase 3: Impact vs. Effort Prioritization
- **Quick Wins:** High impact, low effort (build first).
- **Major Projects:** High impact, high effort (plan next).
- **Fill-ins:** Low impact, low effort.
- **Avoid:** Low impact, high effort.

### Phase 4: Converge & Record
- Translate agreed decisions into components, APIs, and schemas.
- **Mandatory Recording:** Record session notes, decisions (ADRs), and summaries only after the user and assistant actually discuss and agree on them.

---

## 2. Core Principles
- Ask one focused question at a time.
- Present concrete options with pros/cons and trade-offs.
- **Zero Dummy Data Rule:** Never invent or hardcode fake metrics, dummy records, or temporary placeholders.
